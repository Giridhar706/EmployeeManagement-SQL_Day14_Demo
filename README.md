# Employee Management SQL Demo

## 📌 Overview

This project demonstrates core SQL Server concepts including table creation, data manipulation, functions, and stored procedures. It is designed to be executed multiple times safely without errors.

## 🚀 Features

* Clean setup using DROP statements (re-runnable script)
* Table creation and sample data insertion
* Conditional bonus calculation using CASE
* Scalar Function: Annual Salary calculation
* Table-Valued Function: Filter employees by salary
* Stored Procedure: Perform INSERT, UPDATE, DELETE operations
* Clear before-and-after output for better understanding

## 🛠 Technologies Used

* Microsoft SQL Server
* T-SQL

## 📂 How to Run

1. Open SQL Server Management Studio (SSMS)
2. Copy and paste the script into a new query window
3. Execute the entire script

## 📊 Output

* Displays initial employee data
* Shows updated salary after bonus calculation
* Demonstrates function outputs
* Executes stored procedure operations

## 🎯 Purpose

To understand and demonstrate:

* SQL functions vs stored procedures
* Conditional logic using CASE
* Reusable and maintainable SQL scripting
